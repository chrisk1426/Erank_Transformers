Experiment Design

18-Run Seed-Robustness Matrix

3 tasks × 2 architectures × 3 seeds  ·  p = 113, 2-layer transformer

Tasks

  • key_value — look up v(q) from a shuffled context
  • modular_addition — compute (a + b) mod 113
  • hybrid_retrieve_add — y = (v(q₁) + v(q₂)) mod 113
  • context-specific bindings, q₁ ≠ q₂, shuffled kv order, m=4 pairs

Architectures

  • Standard — 2-layer transformer with MLP sublayers
  • Attention-only — 2-layer transformer, MLP sublayers removed
  • Ablates MLP contribution to force attention-only computation
Why this design? If key_value is routing-dominated, attention_only should solve it. If modular_addition needs MLP, attention_only should fail. The hybrid tests whether a model can do both in sequence.
Checkpoint selection: Best validation accuracy. Test accuracy recorded but never used for selection. No test leakage.

The hybrid task did not generalize under this setup. Train accuracy reaches ~83–93% (overfitting) but validation accuracy stays at chance throughout 50,000 epochs. The task appears substantially harder than either component task alone.
Hybrid eRank (seed 0, failed): Σ Δattn = 43.5, Σ Δmlp = 33.5 — both very large compared to the working models (6–11, 0–4). Large eRank ≠ generalization. These numbers are not interpretable as evidence for learned routing + computation; they reflect internal reorganization in a failing model.

A simplified feasibility run (m=3, p=113) is currently running (~12% through). Will determine whether task is solvable at reduced complexity.

Result 4 · Dynamics

Training-Time eRank and Grokking

eRank sampled at checkpoints throughout training  ·  standard modular_addition, seed 0

Standard Modular Addition

  • Train accuracy reaches 99% at epoch 200
  • Val accuracy does not reach 50% until epoch 5,886
  • Grokking gap: ~5,700 epochs between memorization and generalization
  • Attn-vs-MLP dominance shifts twice — at epochs ~500 and ~4,000 — during the generalization phase
  • Suggests continued representational reorganization after memorization

Attention-Only Key Value

  • Train accuracy reaches 99% at epoch 25
  • Val accuracy reaches 50% at epoch 10
  • Σ Δattn peaks at epoch 5 (22.97) — before accuracy peak
  • Geometric peak precedes task solution: attention reorganises, then accuracy follows
Key finding: For modular addition, generalization coincides with a late-layer MLP eRank increase (representational expansion), not compression. The MLP is not simply reducing representation — it is building a richer structure that enables generalisation. This is consistent with the endpoint Δmlp,L1 > 0 finding.

Data from outputs/control_rerun/training_time/ — single seed. New training-time analysis for all 3 seeds should be run on the thesis_additions checkpoints to confirm.

Thesis Claims

Status of Thesis Claims

Where do we stand on the central arguments?

SUPPORTED Claim A: Key-value retrieval is attention-dominated
Σ Δattn ≈ 6.5, Σ Δmlp ≈ −2.6 (robust, 3 seeds). Attention_only architecture also solves perfectly (3/3 seeds). Ablation confirms L1 attn is the most critical component (+0.97 drop). Result is unambiguous and seed-robust.
SUPPORTED Claim B: Modular addition requires MLP involvement
Standard: 3/3 seeds solved with positive L1 Δmlp. Attention_only: 0/3 seeds solved, near chance. Ablation confirms L1 MLP is highly critical (+0.95 drop, comparable to L1 attn). Both the geometric and causal evidence agree.
INCONCLUSIVE Claim C: Hybrid task combines routing and processing
No successful hybrid run yet. Seed 0 failed at 50k epochs; seed 1 shows same pattern. Without a solved model, the eRank interpretation for the hybrid is blocked. Will reassess after remaining 5 runs complete and m=3 feasibility result arrives.
